AutoCAD AI Automation

Phase 7 thin web wrapper for the existing AutoCAD automation use cases.

Title Block Update Preview or apply title block attribute updates across matching drawings. Line List Extract Read line blocks from a P&ID and generate the Excel line list in outputs/. Place Symbol Plan an AutoCAD symbol placement from natural language and optionally execute it. Consistency Check Compare a P&ID against the latest line list and optionally generate an AI explanation. Generate Vessel Review AI-extracted vessel parameters, then generate a DXF or DWG drawing. Sketch Chat Mode Describe a draft sketch and build it directly in the active AutoCAD drawing. Job History Review recent CLI and API audit records stored in the local SQLite job database.
